# 🩻 X-Ray Disease Detection using CNN & Streamlit

A **Deep Learning based X-Ray Disease Detection system** that uses a **Convolutional Neural Network (CNN)** to analyze X-ray images and predict diseases.  
The project includes a **Streamlit web application** for easy and interactive usage.

---

## 🔗 Live Demo
👉 *(Add your Streamlit Cloud link here after deployment)*  
Example: `https://username-x-ray-detection.streamlit.app`

---

## 🚀 Features
- Upload X-ray images for prediction
- Trained CNN model for disease detection
- Clean and interactive Streamlit UI
- Fast inference and easy deployment
- Beginner-friendly and extensible codebase

---

## 🧠 Model Details
- **Architecture:** Convolutional Neural Network (CNN)
- **Framework:** TensorFlow / Keras
- **Model File:** `xray_cnn_model.keras`
- **Input:** X-ray Images
- **Output:** Disease Prediction

## ▶️ Run the Project Locally

### 1️⃣ Clone Repository
```bash
git clone https://github.com/USERNAME/X-Ray-Detection.git
cd X-Ray-Detection
```

### 2️⃣ Install Dependencies
```bash
pip install -r requirements.txt
```

### 3️⃣ Run Streamlit App
```bash
streamlit run app.py
```

---

## 🌐 Deployment (Streamlit Cloud)
1. Push project to GitHub  
2. Go to https://share.streamlit.io  
3. Connect GitHub repository  
4. Select `app.py` as main file  
5. Click **Deploy** 🚀
